# Corrections and examples

Found a broken link, an unclear explanation, or an example that does not work? Open an issue or a pull request and link to the affected video or file.

Keep corrections focused and write in plain English. For code changes, include how to run the example and check the result. Suggestions for clearer explanations and useful examples are welcome.

The lessons themselves are written in Notion, so a fix to a lesson's text may be made there first and then copied here. Your issue or pull request is still the right place to report it.
