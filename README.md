# YouTube content

Notes, examples, and useful files to go with my [YouTube videos](https://www.youtube.com/@gustavonline).

I share what I learn about building software and using AI in everyday business work.

## Where the lessons are written

Every video starts as a lesson in my [YouTube lessons](https://gustavanderson.notion.site/4206d2e17f5681fcb39de978b54b8752) database in Notion. That is where the script, notes, and status live, and where each lesson links to related guides on [Resources](https://resources.onlinesourdough.com). Published lessons can be read there.

This repository holds the files you can use after a video is out: a short introduction, a written explanation you can follow at your own pace, and any prompts, slides, examples, or code. Each video gets its own folder, `videos/<slug>/`, named after its lesson.
